### 🚀 Active Ventures

#### 🎮 **[Witchly.host](https://witchly.host)** — *Founder & Lead Engineer*
*Free Game Server Hosting — Built for Players, Not Profit.*
- Originally founded in August 2021, relaunched with a completely rebuilt stack in 2026.
- Self-hosted infra on Hetzner, Pterodactyl-based with custom automation and Cloudflare proxying.
- Built the full stack — landing page, staff portal, Discord bot, email system, and server management.

#### 📝 **[Docspell](https://docspell.dev)** — *Founder*
*AI-Powered Documentation Platform.*
- Notion-like block editor with AI doc generation straight from GitHub repos.
- Built on Cloudflare Pages + D1 + R2. Gemini API for dev, Claude API for paid users.
- Three-tier pricing: Free / Pro ($16/mo) / Team ($49/mo). Early development.

#### 🛡️ **WitchGuard** — *Founder* *(coming soon)*
*Open-Source Desktop VPN Client.*
- Tauri + React frontend, Rust backend, integrating with wg-easy for self-hosted WireGuard VPNs.
- Multi-server switching, targeting individuals and small teams. Post-Witchly launch.

#### 🗺️ **NIKAL** — *Founder* *(in progress)*
*AI Road Trip Planner for India.*
- Expo SDK + Hono API + PostgreSQL + Gemini Flash. Google Places API for verified data.
- Features: Spot Verdict system, expense splitter, live location sharing, fuel calculator, maps export.
